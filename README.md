# Veer

用 AI 决定流量走向的代理工具：一句话改分流（“Netflix 走日本”），审阅后立即在运行中的 Mihomo 内核生效。

| 目录 | 平台 | 状态 |
|---|---|---|
| [`macos/`](macos/) | macOS 26（SwiftUI） | 第 1 阶段：导入配置、运行内核、切换节点、系统代理、菜单栏 |

macOS 版共用 [SpectreAX/veer-editor](https://github.com/SpectreAX/veer-editor) 的 `VeerCore` 与 `VeerUI`，构建时需要把它检出在本仓库旁边（`../veer-editor`）。计划见 [`macos/docs/PLAN_2026-10-29.md`](macos/docs/PLAN_2026-10-29.md)。
