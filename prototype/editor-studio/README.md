# Veer Editor Studio：重设计原型

Veer 编辑器的完整 UI/UX 重设计，以可点击的网页原型交付。确认后再移植到 SwiftUI。不修改 `native/macos`、`prototype/ai-editor` 或其他原型。

运行（无需安装依赖）：

```sh
python3 -m http.server 4320 --bind 127.0.0.1 --directory prototype/editor-studio
```

打开 http://127.0.0.1:4320/ 。测试：`node --test prototype/editor-studio/state.test.mjs`。

## 设计方向

保留 Veer 的绿色标识与系统字体，不采用其他产品的品牌色或外观。参考了 `Caho1/open-claude-ui` 记录的**通用**交互模式，没有复制其代码、常量或视觉身份。该仓库自述为对 Claude 桌面端的逆向结果，代码来源与授权不明确，因此只借鉴业界通用的做法：

| 模式 | 在 Veer 中的用途 |
|---|---|
| 分层表面（底色 → 侧栏 → 内容 → 浮层）与细边框 | 用明度差和 1px 半透明边框分层，不用阴影堆叠 |
| 自动增高输入框，`/` 与 `@` 触发补全 | `/` 选择操作，`@` 选择服务或出口，消除“走日本”的歧义 |
| 工具调用式的逐项审批卡片 | 每项服务修改单独“接受／拒绝”，只写入接受的项 |
| 可折叠的处理过程，运行时锁定展开 | 处理步骤用 grid 0fr→1fr 展开；运行中不能折叠 |
| 跟随到底与“回到最新” | 上翻即停止跟随；滚动边缘渐隐遮罩 |
| 可调宽度的分栏 | 对话与检查器之间可拖拽（4px 死区）、双击复位、键盘调整 |
| 输入法保护 | 拼音候选期间的回车和方向键不会发送或移动补全 |

所有视觉值都在 `style.css` 顶部定义为 token（颜色、间距 4/8/12/16/24/32/48、圆角 6/8/12/16/20、动效 120/200ms）；组件不自行发明数值。减少动效时取消动画，强制颜色模式下补充边框。

## 信息结构

- **侧栏：会话**。每次导入成为一个会话，含配置、对话、草稿与撤销栈；可搜索、切换、删除。圆点表示有未导出的修改。会话保存在本机（原型使用浏览器存储；会话 Key 永不保存）。
- **对话**：用户指令 → 处理步骤 → 逐项审批卡片 → 校验结果 → 写入／全部拒绝／撤销。AI 的澄清以问题与建议呈现，不算失败。
- **检查器**（⌘I）：
  - **变更**：当前选中轮次的 rules Diff，只包含已接受的项。
  - **规则**：完整草稿，可筛选；高亮上次导出后新增的行。
  - **测试**：输入域名，按顺序找到首条命中规则与出口；如有待审批修改，同时显示写入后的结果。GEOSITE、GEOIP、IP 规则需要内核数据，会明确标为“已跳过”，不猜测。
- **页头**：出口地区（徽标显示未指定数量）、导出（⌘E，先确认增删数）、检查器、深浅色。

## 状态覆盖

导入前、开始页（含未指定地区确认）、处理中、待审批、部分拒绝、全部拒绝、已写入、已撤销、已失效、无需修改、校验失败（不能写入）、校验器不可用、请求失败（可重试）、AI 澄清、AI 缺少 Key、编辑服务启动中、编辑服务不可用（可重启，会话保留）、空会话列表、无匹配搜索、长名称。

## 已验证

- 状态测试 8/8：逐项审批、撤销、@ 精确出口、/ 与 @ 补全、域名匹配、会话、持久化（会话 Key 不恢复、中断请求恢复为已取消）、澄清、校验失败、地区更正。
- 内置浏览器：1440×900 浅色与深色、1080×760（检查器替换对话）、390×844 长名称（抽屉侧栏，无横向溢出）。真实键入走通 `@` 补全，以及澄清、校验失败、服务停止与恢复、导出、刷新后会话保留；控制台无错误。

未验证：屏幕阅读器朗读、真实中文输入法组字、强制颜色模式。

## 移植到 SwiftUI（已完成，见 native/macos/README.md）

1. `VeerEditor`：会话存储（Application Support 下的 JSON，不含 Key 与订阅链接）、逐项决策与部分写入、域名匹配（与服务端规则顺序一致）。
2. 编辑服务：plan 接口返回每项修改的独立规则，供部分写入后重新校验。
3. `VeerMac`：会话侧栏（`List` + 搜索）、`/` `@` 补全弹层（`NSTextView` 包装，处理 marked text）、审批卡片、检查器三标签与可调分栏（`HSplitView` 或自定义拖拽）。
4. 沿用现有的服务状态、地区确认、导出确认与校验三态。
