# Visual design

- Use semantic system colors, system typography and SF Symbols.
- Support light and dark. One appearance's screenshot proves nothing about the other.
- Avoid arbitrary gradients, shadows, borders and corner radii.
- Do not imitate a different macOS release or recreate system materials by hand.
- Keep glass on controls and navigation, not on content.

For every significant screen, review the standard, narrow and wide window sizes, in light and dark.
