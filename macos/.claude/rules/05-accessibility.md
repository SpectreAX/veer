# Accessibility

Accessibility is part of implementation, not polish.

- Use semantic native controls. Custom controls must expose correct roles and values.
- Label icon-only controls. Add a hint only when it says something new.
- Do not add labels that make VoiceOver repeat the visible text.
- Group related elements so VoiceOver navigation stays sensible.
- Support keyboard navigation and keep focus visible.
- Do not convey meaning through color alone.
- Respect Reduce Motion.
- Check contrast.
