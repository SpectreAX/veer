# Veer for macOS：需求（2026-10-29）

本文记录 Veer 要做什么、为谁做、做到什么程度。所有决定都来自 2026-10-29 的四轮追问。具体行为见 [SPEC.md](SPEC.md)，开发步骤见 [PLAN.md](PLAN.md)。它们取代 [PLAN_2026-10-29.md](PLAN_2026-10-29.md) 的第 2 至第 4 阶段。

## 产品

Veer 是一个 Mihomo 代理客户端，让 AI 来决定流量走向。用户说一句话（比如“Netflix 走日本”“为什么 GitHub 走了代理”“ChatGPT 换到最快的美国节点”），Veer 就改分流、解释路由或操作运行中的内核。

- **目标用户：** 已经有订阅、但不懂规则和 YAML 的普通 Mac 用户。懂 Clash 的老用户也能用，但界面不为他们优化。
- **和 Veer AI Editor 的区分：**
  - Veer 用 AI 管理自己正在运行的这份配置，可以导出这份配置。
  - Editor 继续面向给别的客户端或路由器编辑 YAML 的人，支持多文件编辑和各种导出。
- **平台：**
  - 本文只覆盖 macOS，最低 macOS 14，只发一个安装包。
  - macOS 26 上使用 Liquid Glass，旧系统上用标准材质。如果两套外观以后差别太大，再评估拆成两个版本。
  - iOS 和 Android 以后再做。
- **界面语言：** 简体中文和英语，跟随系统，也可以在设置里切换。文案集中管理，以后可以加其他语言。

## 收费与分发

| 平台 | 方式 |
|---|---|
| macOS | 官网免费下载，Developer ID 签名并公证（测试阶段只用免费的 Apple Development 证书，发布前再加入付费计划）。设置和“关于”页有 GitHub Sponsors 和爱发电的赞助链接，不弹窗、不催促 |
| Mac App Store（付费支持版） | 暂缓。App Store 不允许以独立 root 进程运行 Mihomo，必须改用 Network Extension，而 Mihomo 是 GPL-3.0。要等 iOS 内核选型有结论后再一起做 |
| iOS、Android | 一次性买断，14 天试用，以后再做 |

- macOS 版没有授权校验，也没有试用期。
- AI 使用用户自己的 Key，或本机 Ollama。Veer 不运营任何服务器，不收集遥测数据。
- 不设发布日期：所有“必须”项完成并在实机上验证后才发布。

## 许可证约束

- Veer 保留所有权利，仓库私有。
- **Mihomo：** 发布标签上的许可证是 GPL-3.0。它只作为独立程序随应用附带，Veer 通过本机 HTTP 控制它，不链接它的代码。随应用附带它的许可证和对应源码信息。
- **只能参考功能和交互、不能使用代码的项目：** FlClash、Bettbox、Doona（都是 GPL-3.0）。
- **塔台（pengchujin/tower，MIT）：** 可以复用个别代码，比如地区识别表，复用时附上它的许可证。

## 功能范围

### AI（Agent）
| 能力 | 级别 |
|---|---|
| 一句话改分流：生成规则或策略组改动，在运行中的内核立即生效 | 必须 |
| 解释路由：根据实时连接说清命中了哪条规则，并给出一键修正 | 必须 |
| 一句话操作运行状态：切节点、切模式、测速、关闭连接 | 必须 |
| 主动建议：连接反复失败、经常落到 MATCH、节点超时时提示，从不自动应用 | 应做 |

- **改动存放：** AI 和手动的修改都放在独立的“我的分流”层。订阅内容原样保存；订阅更新后重放这些修改，失效的修改要提示用户，不能悄悄丢掉。
- **审批：**
  - 运行状态操作立即执行，并可以撤销。
  - 配置改动显示差异卡片，点“应用”后才生效，生效后也可以撤销。
  - 保留五种执行模式（自动、手动、自动写入、计划、完整权限），默认是手动。
- **发给 AI 的数据：**
  - 默认只发匿名化后的配置。
  - 只有用户问路由原因时，才附上相关连接的域名和命中的规则。
  - 服务器地址、密码和订阅链接永远不发。
  - 每条消息都能看到这次发送了什么。

### 代理
| 功能 | 级别 |
|---|---|
| 概览：速率、流量、出口 IP 和地区 | 必须 |
| 代理组：切换节点、测速 | 必须 |
| 订阅：导入（链接、文件、剪贴板、`clash://`）、更新、自动更新、已用和剩余流量、到期时间及提醒 | 必须 |
| 节点地区离线识别，世界地图上显示节点和延迟（参考塔台） | 必须 |
| 刷新订阅时保留用户取消勾选的节点（参考塔台） | 必须 |
| 连接页：实时查看、关闭连接、筛选、问 AI、为这个域名添加规则 | 必须 |
| 日志页 | 必须 |
| 系统代理、TUN | 必须 |
| 菜单栏、开机启动、全局快捷键 | 必须 |
| 基础覆写：端口、允许局域网连接、IPv6、DNS、进程匹配、日志级别、禁用 QUIC | 必须 |
| 导出配置：合并“我的分流”之后的 mihomo YAML | 必须 |
| 首次使用引导 | 必须 |
| 崩溃后恢复系统代理和路由 | 必须 |
| 检查更新（Sparkle） | 必须 |
| 请求页（已关闭的连接） | 应做 |
| 路由地图：一条连接从规则到策略组再到节点的路径（参考 Doona） | 应做 |
| DNS 查询记录页（参考 Doona） | 应做 |
| 配置诊断，能跳到出错的位置（参考 Doona） | 应做 |
| 内置离线规则模板（ACL4SSR） | 应做 |
| geo 数据更新 | 应做 |
| 本地备份和恢复 | 应做 |
| 诊断包：用户手动导出，自己决定发不发 | 应做 |

### 不做
- JS 覆写脚本（由 AI 替代）。
- WebDAV、iCloud 同步、局域网共享。
- 原始 YAML 编辑器。
- 自定义主题色、可调整大小的概览卡片。
- 导出 mihomo 以外的格式（Surge、sing-box 等）。
- 复制 FlClash、Bettbox、Doona 的代码。

## 界面方向
- **主窗口是主角：**
  - 代理部分的体验参考 FlClash，代理组和节点用卡片网格显示。
  - Agent 部分的体验参考 Codex 和 Claude 应用：对话列表、居中的对话、底部输入框、可以展开的工具调用记录。
- **菜单栏：** 只放开关、模式、当前节点、实时速率和打开主窗口，不放 AI 输入框。
- **关闭主窗口后：** 应用留在菜单栏，代理继续运行。
- **外观：** 原生 macOS 风格，支持浅色和深色，沿用 `VeerUI` 的设计令牌。
