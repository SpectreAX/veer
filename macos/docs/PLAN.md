  - 如果用的是手动安装：输入一次密码后安装成功；重新编译 Veer 后 TUN 仍然能用（Apple Development 签名）；卸载后 `/Library/LaunchDaemons/` 和 `/Library/PrivilegedHelperTools/` 里没有残留。

### 第 5 步：订阅增强
- 节点地区离线识别、手动标记、世界地图视图。
- 订阅自动更新（按 `profile-update-interval`，先直连、失败再走代理）。
- 流量和到期提醒、内置规则模板（打包模板内容前，先确认 ACL4SSR 的许可证）。
- **实机清单：**
  - 用你的真实订阅检查，90% 以上的节点能识别出地区；
  - 地图上点击一个地区，列出的节点正确；
  - 把更新间隔改成 1 小时，到时会自动更新；
  - 剩余流量低于 10% 时收到一次通知。

### 第 6 步：收尾与发布
- **功能：** 全局快捷键、开机启动、Sparkle、备份和恢复、诊断包、主动建议、请求页、DNS 页、路由地图、配置诊断。
- **发布：**
  - 新建公开仓库 `SpectreAX/veer-releases`；
  - DMG 打包、公证，appcast 用 EdDSA 签名；
  - “关于”页放上赞助链接（等你开通 GitHub Sponsors 和爱发电后填入）。
- **实机清单：**
  - 从上一个版本通过 Sparkle 升级到新版本；
  - 用备份恢复到一个新用户账户；
  - 全局快捷键在其他应用里也能用；
  - 公证后的 DMG 在另一台 Mac 上能直接打开，不弹出“无法验证”的提示。

### 第 7 步：Agent 侧边面板
规格见 [SPEC.md](SPEC.md) 6.1。

- **做法：**
  1. 把 Agent 页右栏拆成可复用的 `AgentConversation`（对话、欢迎、未配置 AI、无配置几种状态），加一个紧凑模式（窄边距、简化的未配置提示）。
  2. 修改弹窗（编辑策略组、查看请求内容）、删除确认移到主窗口统一挂载，面板和 Agent 页都能用。
  3. 主窗口加 `.inspector` 面板 `AgentPanel`，开关状态存在 `ProxyStore.agentPanel`（本机设置），工具栏按钮和 `⌥⌘I` 切换；`⌘N` 移到“文件”菜单，全局可用。
  4. 统一入口 `AgentStore.open(asking:)`：在 Agent 页时只填问题，其他页打开面板再填。现有 6 处 `page = .agent` 全部改用它。
  5. 概览顶部的提问栏；概览卡片行按内容宽度自动改为上下排列。
  6. 英文翻译、截图场景（面板打开的概览、连接页、有修改卡片的对话、未配置 AI）、单元测试。
- **实机清单：**
  - 在概览、代理、连接、请求页打开面板，“问 AI”把问题填进面板的输入框；
  - 窗口缩到最小宽度时概览不重叠、不截断；
  - 面板里应用一个修改，撤销可用；点“在 Agent 页打开”后是同一个对话；
  - 关掉面板后重新打开 Veer，面板保持关闭。
