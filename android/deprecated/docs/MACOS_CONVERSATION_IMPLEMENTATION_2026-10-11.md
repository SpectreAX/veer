# macOS 对话原型落地

用户已审阅 Open Design 对话原型，并授权修改程序。

## 范围与实施

- 使用结构化对话记录，右侧用户消息、左侧助手正文及文件修改块。
- Thinking 展示实际请求状态、真实等待时间和可展开记录；服务没有实时细分阶段，不伪造推理或处理进度。
- 文件块保留出口、地区边界、规则详情、带新旧行号的 Diff 和校验结果。
- 确认仅修改本机草稿；记录保留。撤销通过独立快照 ID 标记准确的操作，不把手工编辑或地区调整误认为 AI 修改。
- 取消、失败重试、放弃、候选失效均留在对话中；新请求和草稿变化使旧候选不可确认。
- 保留配置导入、钥匙串、匿名出口、原配置导出保护；不控制代理。

## 验证计划

1. 原生与本机服务集成测试，覆盖确认、第二轮、撤销、放弃、失效和取消。
2. Release 编译与签名打包。
3. 使用无密钥演示配置检查真实窗口、Diff、窄窗口与浅深色，不读取或使用真实订阅和 API key。

## 验证结果

- Swift 测试与本机服务集成：23 项通过（VeerMac 9 / VeerEditor 14）；没有调用真实模型或代理。
- 新增集成用例验证首次确认、香港第二轮、精确撤销、放弃、输入失效、请求取消、手工编辑撤销不误标 AI 记录、缺失德国出口失败，以及发送后清空输入。
- Release 构建、临时签名通过；CLT 环境存在框架搜索路径警告，但不影响构建或测试结果。
- 使用独立 bundle ID 的临时验收副本导入无节点、无密钥的演示配置，实际点击生成、展开处理记录/Diff、确认、第二轮与撤销；原窗口中的真实配置和候选保持不动。
- 原生窗口已检查浅深色。HTML 模拟四阶段未照搬；生产服务没有实时细分阶段接口，只显示真实请求状态。
- 未验证真实 AI 请求、网络出口、服务解锁、VoiceOver 实际朗读和原生 1080×700 像素回归。界面保持 1080×700 最小尺寸及独立滚动布局。
