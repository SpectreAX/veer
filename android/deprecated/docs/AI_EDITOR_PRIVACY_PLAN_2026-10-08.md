# 独立规则编辑模式

本轮范围：本机 Web 原型默认进入独立规则模式，完整 YAML 编辑保留在 `/advanced`。不读取订阅、不连接 Controller、不解析节点服务器、密码或密钥。

输入仅允许手工登记的策略组名称与明确地区，以及只含 `rules` 的 YAML。地区是用户声明，不是节点实测。服务端严格拒绝其他顶级字段及扩展属性，不自动从完整配置抽取规则。

AI 只收到匿名出口编号、用户声明地区与已替换组名的指令。本地保存编号映射并恢复真实组名；模型不能改变映射。规则校验复用现有编辑核心；内核测试使用仅包含占位策略组的合成配置，不能证明真实客户端组名存在或网络可用。

依次验证：输入边界与匿名化 → 添加/删除/冲突/撤销/导出 → 内核占位校验 → 浏览器桌面与窄屏。高级模式必须显式警告本地会读取完整配置。任何模式的 API Key 仍用于向用户选择的模型服务认证；用户指令中的任意敏感信息无法保证自动脱敏，应避免自行输入。

导出仅是 `rules` YAML 片段，非完整配置、非通用客户端覆写模块，不得直接覆盖原配置。按目标客户端的规则合并方式置于原规则之前，或人工合并，并由客户端校验。撤销仅针对本页草稿；不影响运行中的代理。

实现位置：`prototype/ai-editor/core/private-editor.mjs`、专用 `/api/private/*` 接口、`public/private.html` 与 `private.js`。沿用 Impeccable 的双栏编辑／审阅工作台和既有设计系统；依据 Ponytail 复用规则核心与原有依赖。独立只读代码复核 pass。

## 验证结果

30/30 自动化测试通过，0 跳过；依赖审计 0 漏洞。新增规则输入边界、模型请求匿名化、真实组名回映射、无节点直连/屏蔽/删除、占位核心校验及异步 UI 回归。

浏览器：手工登记演示日本/美国组，10 条多服务预览，确认、撤销、导出及误粘 proxies 拒绝均通过。导出文件仅有 rules，含 10 条规则，不含占位组或节点。桌面与 390px 深色界面复核 pass。匿名模式未重新调用真实外部模型，API 适配层通过模拟响应验证；之前完整模式真实 DeepSeek 5 场景结果仍有效，不能冒充本轮真实调用。
