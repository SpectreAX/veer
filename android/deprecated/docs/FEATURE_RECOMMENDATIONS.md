# Veer 功能开发与优化建议

> 基于 2026-07-31 代码快照的深度分析，对标 FlClash / Clash Verge / Surfboard 等主流软件。

---

## 总览

Veer 当前已完成核心代理引擎、AI 分流、Per-App 分流、自定义 DNS、实时日志、真机兼容性等关键功能。以下建议聚焦于**用户日常使用体验的精细打磨**和**已有数据能力的充分释放**，而非从零构建新系统。

---

## P0：高影响力功能（建议优先实现）

### 1. 活跃连接详情页

**现状**：首页仅展示活跃连接数（`activeConnections` 计数），Go 核心已实现 `ConnectionsSnapshot()` 返回完整连接列表 JSON，`MihomoRepository` 也已有 `getConnections()` 方法解析连接数据，但**没有 UI 页面展示**。

**建议实现**：

- 展示每个连接的目标域名/IP、命中规则、使用的代理节点、协议类型、上下行流量
- 支持按域名/规则/节点搜索与过滤
- 支持关闭单个连接或批量关闭
- 按流量大小 / 连接时长 / 目标域名排序

**数据来源**：`MihomoRepository.getConnections()` 已可用，只需构建 UI 层

**涉及文件**：新建 `ui/connections/` 目录（`ConnectionsScreen.kt`、`ConnectionsViewModel.kt`）

**工作量**：约 2-3 天

**影响**：⭐⭐⭐⭐⭐ — 这是 FlClash/Clash Verge 均有的核心运维功能

---

### 2. 首页流量图表与状态面板升级

**现状**：首页通过 `DashboardRefreshCadence.LIGHTWEIGHT_MS = 1000ms` 的 IPC 轮询获取 `TrafficStats`（总上传/下载字节数 + 活跃连接数），但 UI 仅以**文本数字**展示实时速率，缺少可视化历史趋势。

**建议实现**：
- 实时速率折线图：保留最近 60 秒的速率采样，用 Compose Canvas 绘制上传/下载双线实时图
- 连接状态卡片优化：当前出口节点信息增加国旗 emoji + 节点名称、VPN 运行时长计时器、当前代理模式直观展示

**涉及文件**：`ConnectionStatusRepository.kt`（增加速率历史缓冲）、`MainActivity.kt`（首页图表组件）

**工作量**：约 2 天

**影响**：⭐⭐⭐⭐ — 数据基础完全就绪，仅需 UI 可视化层

---

### 3. 节点页面体验优化

**现状**：节点页面功能完备，但交互体验仍有改进空间。

**建议优化**：
- 节点排序与筛选：按延迟（低→高）、按地区、按名称；按地区标签过滤；隐藏不可用节点
- 节点延迟可视化：颜色指示器（🟢≤100ms / 🟡100-300ms / 🔴>300ms / ⚫超时）
- 节点收藏/常用：收藏常用节点置顶展示

**涉及文件**：`ui/nodes/NodesActivity.kt`、`ui/nodes/NodesViewModel.kt`

**工作量**：约 2 天

**影响**：⭐⭐⭐⭐ — 节点选择是高频操作

---

### 4. AI 交互体验增强

**现状**：AI 功能非常强大，但 UI 表达远不够充分。

**建议优化**：
- AI 操作历史记录：持久化每次操作的指令、来源、结果、生成的规则；支持重新执行和撤销
- AI 指令建议/快捷模板：输入框空白时展示常用指令快捷入口
- 执行过程可视化：多步计划逐步展示进度

**涉及文件**：`core_ai/AiController.kt`、`MainActivity.kt`、新建 `data/AiHistoryStore.kt`

**工作量**：约 3 天

**影响**：⭐⭐⭐⭐⭐ — AI 是 Veer 的核心差异化能力

---

### 5. 导航架构统一（单 Activity）

**现状**：存在多个 Activity（MainActivity、ProfileActivity、NodesActivity、RulesActivity），页面切换有白屏闪烁。

**建议**：迁移到单 Activity + Compose Navigation 架构，消除切换闪烁，增加页面过渡动画。

**工作量**：约 3-4 天（架构级改造，建议在功能稳定后进行）

**影响**：⭐⭐⭐⭐

---

### 6. 独立设置页面

**现状**：各种设置项分散在不同页面中，没有集中的"设置"入口。

**建议**：新建独立设置页面，整合通用设置、代理设置、AI 助手、安全隐私、后台运行、关于等分区。

**工作量**：约 2 天

**影响**：⭐⭐⭐⭐
